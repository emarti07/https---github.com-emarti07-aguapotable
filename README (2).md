# Sistema Agua - Starter (Laravel scaffold)

Este es un **scaffold** ligero para comenzar el Sistema de Control de Cobros de Agua Potable usando **Laravel (recomendado v12+)**.
Incluye:

- Estructura mínima (app, routes, resources, public, database).
- Ejemplos de modelo, controlador, rutas, vistas Blade.
- Migrations iniciales (esqueleto) en `database/migrations`.
- Archivo `.env.example` y `composer.json` sugerido.

Colores sugeridos:
- Azul (principal), Naranja (acciones), Verde (pagado), Rojo (alertas).

Cómo usar:
1. Copia el contenido en tu máquina.
2. Ejecuta `composer install` (requiere PHP y Composer).
3. Configura `.env` y ejecuta `php artisan migrate`.
4. `npm install && npm run dev` (opcional para assets).
